# calll_tracking
### Запуск дизайнера
'pyside6-designer'
### Генерация кода для созданной в ui страницы
'pyside6-uic login.ui -o login.py' 
где login.ui это файл из pyside6-designer в формате ui   

1. Введение
   1.1 Назначение приложения
   1.2 Целевая аудитория

2. Установка и запуск
   2.1 Требования (ОС, Python 3.8+, PySide6)
   2.2 Инструкция по установке (pip install -r requirements.txt)
   2.3 Запуск (python main.py)

3. Руководство пользователя
   3.1 Главное окно и навигация (левое меню, центральная область)
   3.2 Раздел "Кандидаты"
        - Описание полей таблицы: ID, ФИО, Телефон, Email, Статус, Источник, Комментарий, Резюме
        - Возможности: просмотр, поиск (если реализован)
   3.3 Раздел "Журнал звонков"
        - Поля: ID, Дата/время, Кандидат, Результат, Длительность, Комментарий, Действия
   3.4 Раздел "Компании"
        - Поля: ID, Название, Контактное лицо, Телефон, Email, Адрес, Сайт
   3.5 Раздел "Вакансии"
        - Поля: ID, Название, Требования, Контактное лицо, Телефон, Компания, Ссылка
   3.6 Раздел "Статистика звонков"
        - Таблица показателей: Всего звонков, Дозвонились, Заинтересованы, Приглашены, Отказов, Нанято, Средняя длительность, Эффективность

4. Техническая архитектура
   4.1 Стек технологий: Python, PySide6, Qt Designer
   4.2 Структура проекта: описание основных файлов (main.py, panel.py, виджеты)
   4.3 Хранение данных: пока тестовые данные, в будущем – SQLite (или укажите, что используется)

5. Возможные ошибки и их решение
   - При запуске ошибка импорта – установите зависимости
   - Не отображаются таблицы – проверьте права на чтение файлов

6. Планы развития (опционально)
   - Добавление редактирования данных
   - Подключение базы данных
   - Экспорт отчётов в Excel
